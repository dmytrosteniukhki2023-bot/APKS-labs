# Архітектура AI-Агента

## Призначення
Агент призначений для автоматизації розгортання та перевірки Python-проєктів із використанням `venv` та `pytest`.

## Компоненти
- **Manifest (`build-engineer.agent.md`)**: Визначає правила роботи, обмеження та дозволи інструмента.
- **Skills (`.github/skills/`)**:
  - `project-scaffold`: створює структуру вихідних файлів.
  - `build-and-test`: створює скрипти віртуального середовища та тести.
  - `github-actions`: створює файл CI.
- **Commands / Prompts (`.github/prompts/`)**: Набір конкретних інструкцій для виконання та перевірки дій.
- **Orchestrator (`init.prompt.md`)**: Запускає ланцюжок команд від ініціалізації до перевірки, перериваючись у разі помилки.
